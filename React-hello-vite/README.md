# React + Vite — Hello World

This is a minimal React app scaffolded for Vite.

PowerShell (Windows) commands to run the project:

```powershell
cd "c:\Nitish\Work\Github\React-hello-vite"
npm install
npm run dev
```

Notes:
- After `npm install` the dev server will start with `npm run dev` and print the local URL (usually http://localhost:5173).
- If your environment prevents fetching packages, you can still inspect the files; to run locally ensure network access for npm.
